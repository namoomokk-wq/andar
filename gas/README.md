# 구글 시트 + Apps Script 연결 방법 (약 5분)

1. https://sheets.google.com 에서 새 스프레드시트를 만든다. (이름 예: `ANDAR IN. MOTION 신청`)
2. 메뉴 **확장 프로그램 → Apps Script** 를 연다.
3. 기본 `Code.gs` 내용을 지우고 이 폴더의 `Code.gs` 전체를 붙여넣고 저장한다.
4. 우측 상단 **배포 → 새 배포 → 유형: 웹 앱**
   - 실행 사용자: **나**
   - 액세스 권한: **모든 사용자**
   - 배포 → 권한 승인 → 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/.../exec`)을 복사한다.
5. `config.js`의 `GAS_URL`에 그 URL을 붙여넣는다.
6. 신청 테스트 후 시트의 `신청` 탭에 행이 쌓이는지 확인한다.

## 주의
- `Code.gs`를 수정하면 **배포 → 배포 관리 → 새 버전**으로 다시 배포해야 반영된다. (URL은 동일)
- 시트에는 연락처 등 개인정보가 쌓이므로 공유 범위를 최소한으로 유지한다.
- 무료 구글 계정 쿼터: 스크립트 실행 시간 하루 90분, 메일 발송 하루 100통.
- 시트 컬럼은 `접수시각, 성함, 연락처, 안다르 아이디, 세션1, 세션2, 브라탑, 집업, 레깅스, 신발, 동의, 인스타 아이디, 우편번호, 주소, 상세주소, 마케팅 동의, 제3자 제공 동의, 유의사항 확인` 순서다. 이미 운영 중인 시트는 1행 헤더의 L~R열에 `인스타 아이디, 우편번호, 주소, 상세주소, 마케팅 동의, 제3자 제공 동의, 유의사항 확인`을 직접 추가한다. (기존 열 순서는 바꾸지 않는다)
- 연락처·안다르 아이디·인스타 아이디(입력 시)는 중복 신청을 거부한다. (주소는 같은 집 가족 신청을 위해 중복을 허용한다)
